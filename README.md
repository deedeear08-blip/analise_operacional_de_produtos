# analise_operacional_de_produtos
Análise Operacional de Produtos`*   Relatório que avalia o desempenho, giro, custo e rentabilidade de cada produto no estoque e nas vendas. O objetivo é identificar gargalos, produtos campeões de venda, produtos parados e oportunidades de otimização da operação para aumentar lucro e reduzir perdas.
